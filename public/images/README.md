# Where to put your images

Replace any sample file with your own using the SAME file name, or change the path in `src/data.js`.

| Folder                 | What it is used for                          | Suggested size |
|------------------------|----------------------------------------------|----------------|
| profile/me.jpg         | Hero polaroid photo                          | 900x1125 (4:5) |
| gallery/photo-1..6.jpg | Polaroid line carousel (square crop)         | 1000x1000      |
| projects/thumb-1..3    | "My projects" folder papers                  | 800x600        |
| ui-ux/thumb-1..3       | "UI/UX" folder papers                        | 800x600        |
| graphic-design/thumb-* | "Graphic design" folder papers               | 800x600        |
| research/thumb-1..3    | "Research" folder papers                     | 800x600        |

Keep each file under ~300 KB (use JPG or WebP) so the page loads fast.
